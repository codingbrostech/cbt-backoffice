# Page

The frame of a list page in the authenticated shell. `Root` is the page's `main` and picks how the page scrolls, and `Header` holds the search bar and anything else above the table.

<Canvas of={PageStories.GridScroll} />

## Usage

`Page` is a set of parts. Always nest them like this, with `DataTable.Root` as a direct child of `Root`. Pass `isPageScroll` to `Root` and to `DataTable.Root` together.

```tsx
<Page.Root isPageScroll>
  <Page.Header>
    <SearchBar.Root>...</SearchBar.Root>
  </Page.Header>
  <DataTable.Root isPageScroll>
    <DataTable.Grid />
    <DataTable.Pagination />
  </DataTable.Root>
</Page.Root>
```

## How the page scrolls

Without `isPageScroll`, `Root` fills the content area and the table takes the height left under `Header`. The rows scroll inside the grid, so the search bar and the pagination never move.

<Canvas of={PageStories.GridScroll} />

With `isPageScroll` on both `Root` and `DataTable.Root`, the table grows with its rows and columns and the content area scrolls as a whole, down and sideways. `Header`, `DataTable.Toolbar` and `DataTable.Pagination` keep the visible width and stay put while the grid scrolls sideways. Use it for a page with a tall header, such as a search bar plus summary cards, or for a wide table.

<Canvas of={PageStories.PageScroll} />

A short or empty list still fills the content area, so the pagination stays at its bottom instead of sitting right under the last row.

<Canvas of={PageStories.PageScrollEmpty} />

Sideways scrolling needs the scrolling element to be a size container (`@container`) that reserves its scrollbar space (`[scrollbar-gutter:stable]`), so `100cqw` is the visible width without the scrollbar. The content area of the authenticated shell already does both.

## Usage in the app

Render it as the page's outermost element. The shell's content area provides the scrolling element.

```tsx
import { Page } from '@cbt-bo/component-lib/components/layout';

<Page.Root isPageScroll>
  <Page.Header>
    <SearchBar.Root defaultValues={defaultFilter} values={filter} onSubmit={search}>
      ...
    </SearchBar.Root>
    <BetTransSummary summary={summary} isLoading={isSummaryFetching} />
  </Page.Header>
  <DataTable.Root
    columns={columns}
    data={rows}
    total={total}
    labels={tableLabels}
    params={pageParams}
    onParamsChange={setPageParams}
    isPageScroll
  >
    <DataTable.Grid />
    <DataTable.Pagination />
  </DataTable.Root>
</Page.Root>;
```
