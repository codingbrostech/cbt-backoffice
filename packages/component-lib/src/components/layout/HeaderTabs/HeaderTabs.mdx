# HeaderTabs

The browser-style tab strip above the page content in the authenticated shell. Each tab is a page the user has visited. Clicking one switches to it, and the tabs close and reorder like browser tabs.

<Canvas of={HeaderTabsStories.Default} />

## Usage

`HeaderTabs` is a set of parts. Always nest them like this. The data goes to `Root`, and each other part takes only the labels it shows.

```tsx
<HeaderTabs.Root
  tabs={tabs}
  activeKey={activeKey}
  onSelect={onSelect}
  onClose={onClose}
  onCloseOthers={onCloseOthers}
  onMove={onMove}
>
  <HeaderTabs.ScrollArea scrollLeftLabel="Scroll tabs left" scrollRightLabel="Scroll tabs right">
    <HeaderTabs.List closeTabLabel="Close tab" />
  </HeaderTabs.ScrollArea>
  <HeaderTabs.Actions
    label="Tab actions"
    closeSelectedTabLabel="Close selected tab"
    closeOtherTabsLabel="Close other tabs"
  />
</HeaderTabs.Root>
```

`Root` is controlled. The caller owns the open `tabs`, their order and the `activeKey`, and decides what happens on `onSelect`, `onClose` and `onMove`. The parts read those values through context. "Close selected tab" in `Actions` closes `activeKey` through `onClose`, and "Close other tabs" closes every tab but `activeKey` through `onCloseOthers`.

## Tabs format

`tabs` is an `IHeaderTab[]`. Each tab has a `key`, usually the page's pathname so it doubles as the navigation target, and a translated `label`.

```tsx
const tabs: IHeaderTab[] = [
  { key: PATH.DASHBOARD, label: t('nav.dashboard') },
  { key: PATH.PLAYERS, label: t('nav.players') }
];
```

## How the strip shows

A tab shows a close button, and the `Actions` menu renders, only while more than one tab is open, since the last remaining tab can't be closed.

<Canvas of={HeaderTabsStories.SingleTab} />

Once the tabs overflow, an arrow button appears at each end while there's more to scroll in that direction, and a vertical wheel scrolls the track sideways.

<Canvas of={HeaderTabsStories.Overflowing} />

Pressing a tab and moving it a few pixels picks it up, the other tabs slide aside as it passes them, and dropping it over another tab calls `onMove` with the dragged key and the key of the tab it landed on. The caller then moves the first to the second's position. Movement is locked to the strip's axis, and the track scrolls when a tab is dragged near an overflowing edge. Only pointer drag is supported, since the arrow keys already move focus between tabs.

<Canvas of={HeaderTabsStories.Reorder} />

With `isDraggable` set to false, the tabs stay in the order given and `onMove` never fires.

<Canvas of={HeaderTabsStories.DragDisabled} />

## Usage in the app

Render it above the page outlet inside `SidebarInset`. Each app's `usePageTabs` hook builds `tabs` from the nav items and the open paths in `usePageTabsStore` from `@cbt-bo/api/page-tabs/store`, and returns handlers that navigate and update the store.

```tsx
import { HeaderTabs } from '@cbt-bo/component-lib/components/layout';

const pageTabs = usePageTabs(items, location.pathname);

<HeaderTabs.Root
  tabs={pageTabs.tabs}
  activeKey={pageTabs.activeKey}
  onSelect={pageTabs.onSelect}
  onClose={pageTabs.onClose}
  onCloseOthers={pageTabs.onCloseOthers}
  onMove={pageTabs.onMove}
>
  <HeaderTabs.ScrollArea
    scrollLeftLabel={t('common.scrollTabsLeft')}
    scrollRightLabel={t('common.scrollTabsRight')}
  >
    <HeaderTabs.List closeTabLabel={t('common.closeTab')} />
  </HeaderTabs.ScrollArea>
  <HeaderTabs.Actions
    label={t('common.tabActions')}
    closeSelectedTabLabel={t('common.closeSelectedTab')}
    closeOtherTabsLabel={t('common.closeOtherTabs')}
  />
</HeaderTabs.Root>;
```
