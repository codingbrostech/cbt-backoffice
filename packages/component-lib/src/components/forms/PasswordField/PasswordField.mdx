**PasswordField** is a `TextField` whose `type` flips between `password` and `text`. A `PasswordToggle` sits in the `suffix` slot, and the visibility state lives inside the field, starting hidden. `disabled` reaches both the input and the toggle.

`showLabel` and `hideLabel` name the toggle for assistive technology and default to English copy, so the apps pass their translated strings through `labels`. Every other `TextField` prop is accepted except `type` and `suffix`, which the field owns.

## Usage

```tsx
import { LockIcon } from 'lucide-react';

import { PasswordField } from '@cbt-bo/component-lib/components/forms';

<PasswordField
  control={form.control}
  name="password"
  label={labels.password}
  placeholder={labels.password}
  prefix={<LockIcon />}
  autoComplete="current-password"
  showLabel={labels.showPassword}
  hideLabel={labels.hidePassword}
/>;
```

## Stories

Each story creates its own form and seeds the bound field with `value`. `Revealed` presses the toggle for you and checks that the input switches to `type="text"`.
