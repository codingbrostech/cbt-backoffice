**PasswordToggle** is the eye button that flips a password input between hidden and shown. It is controlled. `isVisible` picks the icon and the accessible name, and `onToggle` asks the owner to flip it. `showLabel` names the button while the password is hidden and `hideLabel` while it is shown, both defaulting to English copy, and `aria-pressed` mirrors `isVisible`.

`PasswordField` renders it in the `suffix` slot of a `TextField` and owns the state, so pages rarely render it directly.

## Usage

```tsx
import { useState } from 'react';

import { PasswordToggle } from '@cbt-bo/component-lib/components/forms';

const [isVisible, setIsVisible] = useState(false);

<PasswordToggle
  isVisible={isVisible}
  showLabel={t('login.showPassword')}
  hideLabel={t('login.hidePassword')}
  onToggle={() => setIsVisible(prev => !prev)}
/>;
```
