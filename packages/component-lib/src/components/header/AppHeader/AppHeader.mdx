# AppHeader

The top bar of an authenticated page. The brand mark sits at the start, and the clock, theme toggle, language menu and user menu line up at the end on the sidebar colors.

<Canvas of={AppHeaderStories.Default} />

## Usage

`AppHeader` is a set of parts that only lay the bar out. Nest them like this, and give each control inside its own props.

```tsx
<AppHeader.Root>
  <AppHeader.Start>
    <BrandLogo icon={icon} brandName="Backoffice" />
  </AppHeader.Start>
  <AppHeader.End>
    <TimezoneClock timezoneMinutes={480} isTimezoneSelectable={false} />
    <AppHeader.Separator />
    <ThemeToggle theme={theme} onThemeChange={setTheme} />
    <LanguageMenu currentLanguage="en" options={languageOptions} onChange={setLanguage} />
    <AppHeader.Separator />
    <UserMenu userName="admin" logoutLabel="Logout" onLogout={logout} />
  </AppHeader.End>
</AppHeader.Root>
```

Every part also takes a `className`.

## What goes inside

The parts carry no data of their own. Each control is a standalone component from the same `header` barrel and is documented on its own page: [BrandLogo](?path=/docs/header-brandlogo--docs), [TimezoneClock](?path=/docs/header-timezoneclock--docs), [ThemeToggle](?path=/docs/header-themetoggle--docs), [LanguageMenu](?path=/docs/header-languagemenu--docs) and [UserMenu](?path=/docs/header-usermenu--docs). Leave a control out of `End` to hide it. `BrandLogo` reads the sidebar rail state, so the header needs a `SidebarProvider` above it.

The controls below are grouped by the component that takes them.

## How the bar shows

`TimezoneClock` with `isTimezoneSelectable` set to `false` keeps the time on `timezoneMinutes` and hides the select.

<Canvas of={AppHeaderStories.FixedTimezone} />

Leaving the clock and its `Separator` out of `End` drops that cluster.

## Usage in the app

Render it as the first child of the `SidebarProvider` in the authenticated layout, above the row holding `AppSidebar` and `SidebarInset`. The timezone and theme come from `usePreferencesStore` in `@cbt-bo/api/preferences/store`, the language from i18n, and the user from the route context. Every label arrives already translated.

```tsx
import {
  AppHeader,
  BrandLogo,
  LanguageMenu,
  ThemeToggle,
  TimezoneClock,
  UserMenu
} from '@cbt-bo/component-lib/components/header';

<AppHeader.Root>
  <AppHeader.Start>
    <BrandLogo
      icon={<img src={brandIcon} alt={t('login.brandName')} className="size-5 rounded-sm" />}
      brandName={`${t('login.brandName')} ${t('login.title')}`}
    />
  </AppHeader.Start>
  <AppHeader.End>
    <TimezoneClock timezoneMinutes={timezoneMinutes} isTimezoneSelectable={false} />
    <AppHeader.Separator />
    <ThemeToggle
      theme={theme}
      onThemeChange={setTheme}
      lightLabel={t('common.theme.light')}
      darkLabel={t('common.theme.dark')}
    />
    <LanguageMenu
      currentLanguage={i18n.language}
      options={LANGUAGE_OPTIONS}
      onChange={handleLanguageChange}
    />
    <AppHeader.Separator />
    <UserMenu
      userName={user.name}
      userRole={user.role}
      logoutLabel={t('common.logout')}
      onLogout={handleLogout}
    />
  </AppHeader.End>
</AppHeader.Root>;
```
