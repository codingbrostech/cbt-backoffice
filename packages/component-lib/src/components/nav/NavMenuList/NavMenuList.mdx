**NavMenuList** renders a list of nav items. A leaf becomes a menu button wrapped by `renderLink`, which lets the host app supply its own router link. A group becomes a toggleable heading followed by its children, recursing for deeper groups. `onNavigate` fires after a leaf is chosen, which `AppSidebar` uses to close its popover.

It is built on the shadcn sidebar menu primitives, so it expects to sit inside a `Sidebar` under a `SidebarProvider`. `AppSidebar` renders it in both the docked column and the collapsed popover.

Hovering a group heading swaps its icon for a chevron that invites the toggle. The chevron points down while the group is expanded and right once it is collapsed. The two hover stories below force that hover state on the heading through the pseudo-states addon, so the chevron shows without a mouse.

## Usage

```tsx
import { NavMenuList } from '@cbt-bo/component-lib/components/nav';

<NavMenuList
  items={group.children}
  activeKey={activeKey}
  renderLink={(item, children) => <Link to={item.path}>{children}</Link>}
  onNavigate={closePopover}
/>;
```
