# AppSidebar

The left nav rail of the admin pages. It shows one button per top-level nav item. A top-level item with children opens them in a panel beside the rail, and the rail can collapse to icons only.

<Canvas className="w-fit" of={AppSidebarStories.Expanded} />

## Usage

`AppSidebar` is a set of parts. Always nest them like this, and pass data only to `Root` and `Toggle`.

```tsx
<AppSidebar.Root items={items} activeKey={activeKey} renderLink={renderLink}>
  <AppSidebar.Rail>
    <AppSidebar.Menu />
    <AppSidebar.Footer>
      <AppSidebar.Toggle openLabel="Open sidebar" closeLabel="Close sidebar" />
    </AppSidebar.Footer>
  </AppSidebar.Rail>
  <AppSidebar.Panel />
</AppSidebar.Root>
```

`activeKey` is the `key` of the leaf for the current page. Get it with `buildActiveNavKey(items, location.pathname)`, and leave it out when no leaf matches. `renderLink` turns a leaf into the app's router link, so return `<Link to={item.path}>{children}</Link>`.

## Items format

`items` is a `TNavItem[]` with two kinds of item. A **leaf** has a `path` and navigates there. A **group** has `children` instead of a `path` and opens them. A child can itself be a group. Every item has `key`, `label` and `pageKey`, and top-level items usually have an `icon`. Build the list once per language so labels arrive translated.

```tsx
const items: TNavItem[] = [
  {
    key: 'dashboard',
    label: t('nav.dashboard'),
    icon: <LayoutDashboard />,
    pageKey: 'dashboard',
    path: PATH.DASHBOARD
  },
  {
    key: 'player',
    label: t('nav.player'),
    icon: <Users />,
    pageKey: 'player',
    children: [
      {
        key: 'player-mgmt',
        label: t('nav.playerMgmt'),
        icon: <Users />,
        pageKey: 'playerMgmt',
        children: [
          { key: 'players', label: t('nav.players'), pageKey: 'players', path: PATH.PLAYERS },
          {
            key: 'player-sessions',
            label: t('nav.playerSessions'),
            pageKey: 'playerSessions',
            path: PATH.PLAYER_SESSIONS
          }
        ]
      },
      {
        key: 'player-labels',
        label: t('nav.playerLabels'),
        icon: <Tag />,
        pageKey: 'playerLabels',
        path: PATH.PLAYER_LABELS
      }
    ]
  }
];
```

## How parent and child show

A top-level item is a button on the rail with its icon and label. Clicking a group docks its children in the panel.

<Canvas className="w-fit" of={AppSidebarStories.GroupDocked} />

The panel also opens on its own for the group that contains `activeKey`, so landing on `/players` shows the Player button as active, opens the panel, and highlights Players. A child that is itself a group, like Player Mgmt, shows in the panel as a section that expands and collapses.

<Canvas className="w-fit" of={AppSidebarStories.SectionExpanded} />

Hovering a section heading swaps its icon for a chevron, pointing down while the section is expanded and right once it is collapsed. A collapsed heading shows as active while it hides the active page.

<Canvas className="w-fit" of={AppSidebarStories.SectionCollapsed} />

Collapsed, the rail shows icons only and each button names itself in a tooltip.

<Canvas className="w-fit" of={AppSidebarStories.Collapsed} />

A group opens its children in a popover instead of the panel.

<Canvas className="w-fit" of={AppSidebarStories.CollapsedPopover} />

## Usage in the app

Render it inside the `SidebarProvider` that already wraps `AppHeader`, in a row beside `SidebarInset`. `Root` carries `data-panel-docked` while the panel is open, and the inset reads it to square off its left corner.

```tsx
import { AppSidebar, buildActiveNavKey } from '@cbt-bo/component-lib/components/nav';
import { SidebarInset } from '@cbt-bo/component-lib/components/ui/sidebar';

const items = buildNavItems(t);
const activeKey = buildActiveNavKey(items, location.pathname);

<div className="flex min-h-0 flex-1">
  <AppSidebar.Root
    items={items}
    activeKey={activeKey}
    renderLink={(item, children) => <Link to={item.path}>{children}</Link>}
  >
    <AppSidebar.Rail>
      <AppSidebar.Menu />
      <AppSidebar.Footer>
        <AppSidebar.Toggle
          openLabel={t('common.openSidebar')}
          closeLabel={t('common.closeSidebar')}
        />
      </AppSidebar.Footer>
    </AppSidebar.Rail>
    <AppSidebar.Panel />
  </AppSidebar.Root>
  <SidebarInset className="rounded-sm rounded-tl-md [[data-panel-docked]+&]:rounded-l-none">
    <Outlet />
  </SidebarInset>
</div>;
```

## Widths

The widths are CSS variables on `Root`. A `className` on `Root` overrides one for the whole sidebar, for example `[--app-sidebar-panel-width:18rem]`.

- `--app-sidebar-rail-width` defaults to `5rem`
- `--app-sidebar-rail-width-collapsed` defaults to `3.5rem`
- `--app-sidebar-panel-width` defaults to `14rem`
